# 南大实验室安全助手（题库采集 + 考试助手）

南京大学实验室安全学习平台（`aqxx.nju.edu.cn`）的二合一浏览器用户脚本。
右下角一个面板、顶部一个切换栏，两个功能坐在一起：

| 页签       | 干什么                                         |
| -------- | ------------------------------------------- |
| **题库采集** | 自动刷「题库练习」，把题目与答案沉淀到浏览器本地题库，支持导出 JSON / CSV  |
| **考试助手** | 在「我的考试」自动进入考试 → 用本地题库作答 → 交卷 → 交卷后自动回收错题补题库 |

两个页签共用**同一份**本地题库：采集器采到的题，考试助手那边立刻能用；考试助手回收的错题，也回到同一个题库里。

---

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）扩展。
2. 打开 `南大实验室安全助手.user.js` 的 raw 链接，Tampermonkey 会弹出安装页，点「安装」即可。
   - 也可以在 Tampermonkey 的「添加新脚本」里把文件内容整段粘进去保存。
3. 打开 <https://aqxx.nju.edu.cn/>，右下角就会出现面板。

`@match` 只匹配 `*://aqxx.nju.edu.cn/*`，不会跑到别的站点上去。

## 用法：三步走

### 第一步 · 采集题库（页签「题库采集」）

停在「题库练习」页，选好采集方式，点**开始**：

| 方式                    | 说明                                                              | 耗时             |
| --------------------- | --------------------------------------------------------------- | -------------- |
| **自动点击页面 · 快速拉取**（默认） | 脚本替你点：选题库类型 → 开始练习 → 填 1~题数 → 确定，再靠接口直采把这一批题目收下来入库              | 19 个题库约 1~2 分钟 |
| **自动点击页面 · 逐题点击**     | 进去后一道道走：选 A → 下一题 → 看有没有翻页判断对错，答错就读页面渲染的「正确答案：X」                | 慢，但过程可见、可交叉验证  |
| **直连接口 · 不点页面**       | 完全不碰 DOM，直接向后端要数据（`queryCountList` → `queryListByType`）。任何页面都能跑 | 全站约十几秒         |

- **接续采集**：范围「从」留空 = 自动接续，跳过已经整库跑完的题库；中断后再点开始会自动续上。
  下拉里带 `✓已采集` 的就是已完成的。想重跑就指定具体的题库。
- **答案来源与可信度**：接口直采（含解析）＞ 错题反查 / Vue 反查 ＞ A 命中。
  同一条题干按规范化题干哈希去重，高可信来源会覆盖低可信来源。
- 采完点**导出 JSON**（或 CSV）留一份档。

### 第二步 · 加载题库（页签「考试助手」）

点**加载题库**，选上一步导出的 `.json` 或 `.csv`。**这一步只要做一次**：数据进了浏览器本地存储，
之后刷新、关页面都还在，不用每次选文件。

> 浏览器不允许网页脚本自己读本地文件，必须由你手选一次。所以脚本和题库文件**没有任何路径绑定** ——
> 文件挪走、改名、删掉都不影响已经加载的数据。
> 换浏览器 / 无痕窗口 / 换电脑 / 清了该站点的数据之后，需要重新加载一次。

### 第三步 · 考试

打开 <https://aqxx.nju.edu.cn/students/questionList>（「我的考试」）：

1. 下拉框选目标试卷 → 选「正式考试 / 模拟考试」→ 点 **① 进入考试**。
2. 答题弹窗出现后脚本立刻做一次**预检**：逐题比对本地题库，告诉你命中多少、未命中多少（只读，不动界面、不消耗次数）。
3. 确认无误后点 **② 填答并发卷**，脚本按你选的模式作答并交卷。
4. 开了「交卷后回收错题」的话，交卷后会自动去点该行「错题集」，把这一轮做错的题连同正确答案补进本地题库。

> ★ 建议先跑**模拟考试**（不计入成绩）来补题，题库补得差不多了再上正式考试。

## 面板上的开关

### 题库采集

| 控件                                      | 说明                                 |
| --------------------------------------- | ---------------------------------- |
| 从 / 到                                   | 采集范围。「从」留空 = 自动接续（跳过 `✓已采集`）       |
| 方式                                      | 上面三种采集方式                           |
| 接口入库                                    | 拦截接口响应整批入库（含解析）。在「逐题点击」模式下用不上，会被灰掉 |
| 最后一题自动判定                                | 逐题模式下，最后一题点「提交」触发判定后入库             |
| 间隔                                      | 翻页节流。逐题模式有自己的一套节流，会被灰掉             |
| 导出 JSON / 导出 CSV / 复制题库 / 清空题库 / 重置采集进度 | 字面意思                               |

### 考试助手

| 控件                    | 说明                                                             |
| --------------------- | -------------------------------------------------------------- |
| 试卷                    | 目标试卷行（内容是页面上的考试表格，已考/限考一并标出）                                   |
| 类型                    | 正式考试 / 模拟考试（不计入成绩）                                             |
| 模式                    | **逐题作答**（可视化，一道道翻页真的点选项）/ **极速填答**（一次写好整卷 `param`，跳到最后一题交卷，几秒） |
| 兜底                    | 题库未命中的题怎么答：留空（默认）/ 全选 A / 随机                                   |
| 近似                    | 模糊匹配阈值，**默认关闭**，原因见下                                           |
| 进入考试后自动填答             | 打开后进入考试不再二次确认，直接作答交卷                                           |
| 自动点提交并确认              | 关掉就停在「确认提交试卷?」等你手动点                                            |
| 交卷后回收错题补充题库           | 交卷后自动去点「错题集」，把错题和正确答案补进本地题库                                    |
| 接口入库（startExam / 错题集） | 拦截接口里的 `correctAnswer`。**两个页签共用一个钩子：任一侧开着就生效，两侧都关才停**          |
| 诊断 / 导出未命中            | 自检打到控制台 / 把本卷未命中的题干导成 CSV                                      |

### ⚠️ 关于「模糊匹配」

默认**关闭**，而且建议就让它关着。

题库里同模板的题只差一个题号，例如
`单选题第61题：以下关于…，正确的是（　）。` 与 `单选题第70题：以下关于…，正确的是（　）。`，
字符二元组相似度就有 **0.97** —— 光看题干必然误判成同一题，答案全错还看不出来（这是实测踩过的坑）。

就算打开，也还有一层护栏：判断题一律不参与模糊匹配（它的选项恒为「正确/错误」，没有区分度）；
单选/多选必须 A~D 里所有能对上的选项文字全部一致才认。被挡掉的条数会在预检里以「模糊被挡」显示。

### 预检结果怎么看

```
共 95 题 · 命中 93 题（接口随卷 0 / 精确 88 / 宽松 5 / 同形多解 2 / 选项校正 3 / 选项冲突 1）· 未命中 2 题
```

| 字段        | 含义                                    |
| --------- | ------------------------------------- |
| 接口随卷      | `startExam` 直接下发了 `correctAnswer`，最可靠 |
| 精确 / 宽松   | 题库按规范化题干 / 去标点后一致命中                   |
| 同形多解      | 题库里有多条只差括号或标点的同形题干，已按选项文字挑最吻合的一条      |
| 选项校正      | 命中题干但选项顺序不同，按选项文字重新对齐了答案字母            |
| 选项冲突      | 命中但选项文字对不上，只能按题库原字母作答，交卷前建议扫一眼        |
| 模糊 / 模糊被挡 | 模糊匹配通过的 / 被护栏拦下的                      |
| 未命中       | 题库里没有，按「兜底」设置处理                       |

## 两个页签共用什么

- **本地题库**（`localStorage: nju_labsafe_bank_v1`）—— 同一个对象、同一个键。
- **XHR 接口钩子** —— 只装一次，同时抄走页面自己用的 `X-Access-Token` / `tenant-id`，
  并把 `questions/queryListByType`、`exam/startExam`、`exam/unCorrect` 的响应整批入库。
- **提示条** —— 入库了多少题，采集器弹提示、考试助手写日志，两边都会说一声。

| localStorage 键             | 内容                |
| -------------------------- | ----------------- |
| `nju_labsafe_bank_v1`      | 本地题库（两个页签共用）      |
| `nju_labsafe_progress_v1`  | 采集进度（哪些题库已整库跑完）   |
| `nju_labsafe_cfg_v1`       | 采集器配置             |
| `nju_labsafe_exam_cfg_v1`  | 考试助手配置            |
| `nju_labsafe_suite_cfg_v1` | 外壳配置（当前页签 / 折叠状态） |

题库大了会撞 localStorage 配额（约 4000 条 / 2MB）。真写不进去时面板会明确提示，
这时内存里的数据还在，但刷新就没了 —— 请立刻点「导出题库」留档。

## 控制台入口

```js
__labsafeSuite.switchTab('exam')        // 切换页签：'collect' | 'exam'
__labsafeSuite.bank.total()             // 题库条数
__labsafeSuite.bank.exportJSON()        // 整库 JSON 字符串
__labsafeSuite.bank.exportCSV()         // 整库 CSV
__labsafeSuite.bank.import(text, 'x.json')

__labsafeSuite.collect.diagnose()       // 采集器自检：当前在不在练习弹窗、认不认得出组件、类型列表…
__labsafeSuite.collect.start() / .stop()
__labsafeSuite.collect.exportJSON() / .exportCSV()

__labsafeSuite.exam.diagnose()          // 考试助手自检：表格行数、recordId、题目数、接口是否带答案…
__labsafeSuite.exam.enter() / .precheck() / .fill() / .diagnose()
__labsafeSuite.exam.importJSON(text) / .exportBank() / .exportMissing()
```

合并前的两个入口也保留着，旧命令照旧能用：`__labsafeBank`、`__labsafeExam`。

## 改脚本的时候

合并后的脚本内部是「共享核心 `LS` + 两个模块 + 外壳」三层结构。改完先跑自检，再去页面上手测：

```bash
node tools/check.js
```

它会做三件事：语法编译、扫出"被调用但没声明"的标识符（重构时最容易漏的就是 `LS.` 前缀）、
以及检查结构是否还完整（两个模块都在、XHR 钩子只装一次、题库仍走共享引用而不是被整体替换）。

两个模块之间的约定：

- 题库只有一份，`state.bank` / `state.total` 都是取值器（getter），**不要给它们赋值** ——
  赋值不会生效，也不会换掉共享引用，但会让人误以为换掉了。
- 题库变了要发通知（`LS.onBankChange` → 考试助手的匹配索引失效重建、两边数字重刷）。
- 接口入库统一走 `LS.ingestApiPayload`，两条等待队列（`waitPracticeIngest` / `waitExamIngest`）分开，
  采集器的「快速拉取」和考试助手的「回收错题」互相不串台。

## 边界与免责

- **安全边界**：`.stem` 这个类名在「题库练习」「我的考试」「课程详情·错题集」三处都用，
  脚本靠 Vue 组件实例的独有字段区分（练习 `questionTypeList` / 考试 `recordId`·`questionNum`·`param`）。
  **认不出组件时一律不动手，绝不猜** —— 避免在考试页面误把整张卷子全选 A 再交上去。
- **不做绕过性操作**：不伪造请求、不改判分、不绕过考试次数限制。它只是"把你自己整理好的题库自动填进去"。
- 采集模式里的「直连接口」只发只读的 GET 查询，不触碰任何考试 / 提交接口。
- 正式考试请自行判断是否使用。**因使用本脚本产生的任何后果由使用者自负**，作者不对成绩、考勤、
  账号状态等任何结果负责。
- 题库数据版权归原平台所有，仅供个人学习自测使用，请勿用于商业用途或二次分发。
